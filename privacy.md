   # Privacy Policy: SEA Backup (rclone)

   This application is used only by its owner, to copy encrypted backup files
   from the owner's server to the owner's own Google Drive.

   - It uses the Google Drive permission only to create and update the backup
     files it uploads, in the owner's own Drive.
   - It does not collect, share or sell any user data, and it has no website
     visitors or other users.
   - The backup files are encrypted before they reach Google Drive.
   - Access can be revoked at any time in the owner's Google Account
     security settings.
